## 核心概念讲解

### 变量声明：JavaScript 的"容器"

想象变量就像一个"容器"或"盒子"，你可以往里面存放不同的东西（数据）。JavaScript 提供了三种方式来创建这些容器：

#### var：老式容器（不推荐使用）

- **特点**：函数作用域，可以重复声明，存在"变量提升"
- **问题**：容易导致意外的变量覆盖
- **类比**：就像一个没有锁的箱子，谁都可以往里面放东西，也容易搞混

```javascript
var name = "John";
var name = "Jane"; // 不报错，但会覆盖之前的值
```

#### let：现代标准容器（推荐）

- **特点**：块级作用域，不能重复声明，可重新赋值
- **优势**：更安全，符合现代编程规范
- **类比**：就像一个带锁的箱子，只有主人可以打开和更换内容

```javascript
let age = 25;
age = 26; // 可以重新赋值
// let age = 27; // 报错：不能重复声明
```

#### const：固定容器（推荐用于常量）

- **特点**：块级作用域，不能重复声明，不能重新赋值
- **使用场景**：定义不会改变的值（如配置项、常量）
- **类比**：就像一个密封的保险箱，一旦放进去就不能更换，但可以修改内部的复杂内容

```javascript
const PI = 3.14159;
// PI = 3.14; // 报错：不能重新赋值

const user = { name: "John" };
user.name = "Jane"; // 可以修改对象内部的属性
```

### 数据类型：JavaScript 识别的"物品类型"

JavaScript 把数据分为两大类：原始类型和引用类型。

#### 原始类型（基本类型）

这些是简单的、不可变的数据：

| 类型 | 说明 | 示例 |
|------|------|------|
| String | 字符串（文本） | `"Hello"` |
| Number | 数字（整数和小数） | `42`、`3.14` |
| Boolean | 布尔值（真/假） | `true`、`false` |
| Null | 空值（表示"无"） | `null` |
| Undefined | 未定义（变量未赋值） | `undefined` |
| Symbol | 符号（唯一标识符） | `Symbol("id")` |
| BigInt | 大整数（超出 Number 范围） | `9007199254740991n` |

**类比**：原始类型就像简单的物品，比如一本书、一个数字、一张卡片。

#### 引用类型（复杂类型）

这些是可以包含多个值的复杂数据：

| 类型 | 说明 | 示例 |
|------|------|------|
| Object | 对象（键值对集合） | `{ name: "John", age: 30 }` |
| Array | 数组（有序列表） | `[1, 2, 3]` |
| Function | 函数（可执行的代码） | `function() {}` |

**类比**：引用类型就像一个文件夹或箱子，里面可以放多个物品。当你复制这个"文件夹"时，实际上只是复制了文件夹的位置，里面还是同一套东西。

### 运算符：JavaScript 的"工具箱"

运算符是 JavaScript 用来处理数据的工具。

#### 算术运算符：计算工具

```javascript
let a = 10, b = 3;
a + b    // 加法：13
a - b    // 减法：7
a * b    // 乘法：30
a / b    // 除法：3.333...
a % b    // 取余（求余数）：1
a ** b   // 幂运算（a 的 b 次方）：1000
```

#### 比较运算符：比较工具

```javascript
let a = 10, b = 3;
a == b   // 相等（不比较类型）：false
a === b  // 严格相等（比较类型和值）：false
a != b   // 不相等（不比较类型）：true
a !== b  // 严格不等于（比较类型和值）：true
a > b    // 大于：true
a < b    // 小于：false
```

**重要提示**：始终使用 `===` 和 `!==` 进行比较，避免类型转换的陷阱。

#### 逻辑运算符：逻辑判断工具

```javascript
let x = true, y = false;
x && y   // 与（两个都为 true 才返回 true）：false
x || y   // 或（有一个为 true 就返回 true）：true
!x       // 非（取反）：false
```

### 条件判断：JavaScript 的"决策机制"

条件判断让程序能够根据不同情况做出不同反应，就像人遇到问题时需要做决策一样。

#### if...else 语句：基本的决策结构

```javascript
let score = 85;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else {
    console.log("Grade: F");
}
```

**类比**：就像考试评分标准，根据分数范围给出不同等级。

#### 三元运算符：简化的决策

```javascript
let message = score >= 60 ? "Pass" : "Fail";
```

**类比**：就是一个简版的 if...else，适合简单的二选一情况。

#### 多条件判断：使用逻辑运算符

```javascript
let age = 20;
let hasLicense = true;

if (age >= 18 && hasLicense) {
    console.log("Can drive");
} else {
    console.log("Cannot drive");
}
```

**类比**：就像驾照考试，既要年龄达标，又要通过考试才能开车。

## 最佳实践

### 变量声明

1. **优先使用 const**：如果变量的值不会改变，始终使用 const
2. **其次使用 let**：只有需要重新赋值时才使用 let
3. **避免使用 var**：var 存在作用域问题，容易导致 bug

```javascript
// 好的做法
const API_URL = "https://api.example.com";
let currentPage = 1;

// 不好的做法
var API_URL = "https://api.example.com";
```

### 数据类型

1. **类型检查**：使用 `typeof` 或 `Array.isArray()` 检查类型
2. **避免隐式类型转换**：使用 `===` 和 `!==` 而不是 `==` 和 `!=`
3. **注意 null 和 undefined**：null 表示"无值"，undefined 表示"未定义"

```javascript
// 好的做法
if (typeof value === "string") { ... }

// 不好的做法
if (value == "string") { ... } // 可能产生意外结果
```

### 运算符

1. **使用严格比较**：始终使用 `===` 和 `!==`
2. **注意运算符优先级**：不确定时使用括号明确优先级
3. **避免连续比较**：`1 < x < 5` 在 JavaScript 中不会按预期工作

```javascript
// 好的做法
if (x > 1 && x < 5) { ... }

// 不好的做法
if (1 < x < 5) { ... } // 逻辑错误
```

### 条件判断

1. **使用有意义的变量名**：条件表达式的含义应该清晰
2. **避免深层嵌套**：使用 return 或 else if 来简化
3. **处理所有可能的情况**：使用 else 或 default 处理边界情况

```javascript
// 好的做法
if (isValid) {
    return process();
}
return defaultValue;

// 不好的做法
if (isValid) {
    if (hasPermission) {
        if (canAccess) {
            return process();
        }
    }
}
```

## 练习题

### 基础练习

1. **声明变量**：使用 let 和 const 声明以下变量
   - 姓名（name）
   - 年龄（age）
   - 是否是学生（isStudent）
   - 圆周率（PI，使用 const）

2. **类型检查**：创建一个函数，接受任意参数，返回它的数据类型

3. **温度转换**：写一个程序，将摄氏温度转换为华氏温度

### 进阶练习

1. **成绩评级**：写一个函数，接受 0-100 的分数，返回评级（A/B/C/D/F）
   - 90-100: A
   - 80-89: B
   - 70-79: C
   - 60-69: D
   - 0-59: F

2. **闰年判断**：写一个函数，判断某年是否是闰年
   - 能被 4 整除但不能被 100 整除，或者能被 400 整除

3. **BMI 计算**：写一个函数，接受身高（米）和体重（公斤），计算 BMI 并返回健康状态
   - BMI < 18.5：偏瘦
   - 18.5 <= BMI < 24：正常
   - 24 <= BMI < 28：超重
   - BMI >= 28：肥胖

### 挑战练习

1. **密码强度检测**：写一个函数，检查密码强度，返回以下评级
   - 弱：少于 6 位或只包含字母
   - 中：包含字母和数字
   - 强：包含字母、数字和特殊字符，且不少于 8 位

2. **简单的计算器**：写一个函数，接受两个数字和运算符，执行相应的运算
   - 支持的运算符：+、-、*、/
   - 处理除数为 0 的情况

3. **数字转换**：写一个函数，将数字转换为中文大写（如：123 -> 一百二十三）
