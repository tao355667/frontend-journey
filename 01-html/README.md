# HTML 基础教程

> 从零开始学习 HTML，构建你的第一个网页

---

## 教程简介

这是一套专为初学者设计的 HTML 基础教程，采用**概念讲解式**的学习方法，帮助你从零开始掌握 HTML 网页开发。

### 教程特点

✅ **循序渐进**：从基础结构到综合应用，逐步深入
✅ **概念讲解**：通俗易懂地解释每个知识点
✅ **实践导向**：每个章节都有完整的代码示例
✅ **练习巩固**：提供基础、进阶、挑战三个层次的练习题
✅ **答案参考**：基础练习题提供参考答案，方便对照学习

## 章节内容

### 1. 基础结构（01-basic-structure）

**学习目标**：学会搭建网页的"骨架"，理解 HTML 文档的基本结构

**内容要点**：

- HTML 的作用和意义
- 文档类型声明、HTML 根元素
- 头部区域（meta 标签、title 标签）
- 主体区域（body 标签）
- 最佳实践（UTF-8 编码、viewport 设置）

**学习时间**：30 分钟

**练习题**：创建一个简单的自我介绍页面

**答案文件**：`practice-solution.html`

---

### 2. 常用标签（02-common-tags）

**学习目标**：掌握网页最常用的内容元素

**内容要点**：

- 文本标签（p、span、h1-h6、strong、em）
- 链接和图片（a、img）
- 列表标签（ul、ol、li）
- 代码与引用（code、pre、blockquote）
- 最佳实践（alt 属性、安全链接）

**学习时间**：1 小时

**练习题**：用学到的标签制作一个学习笔记页面

**答案文件**：`practice-solution.html`

---

### 3. 语义化标签（03-semantic-tags）

**学习目标**：让网页结构更清晰、更有意义

**内容要点**：

- 语义化的价值（可读性、SEO、无障碍）
- 页面结构标签（header、nav、main、footer）
- 内容组织标签（section、article、aside）
- 文本辅助标签（time、address、details）
- div vs 语义化标签

**学习时间**：1 小时

**练习题**：创建一个语义化的博客页面结构

**答案文件**：`practice-solution.html`

---

### 4. 表单与验证（04-forms）

**学习目标**：学会收集用户输入并进行基本验证

**内容要点**：

- 表单容器（form）
- 输入控件（input 的各种类型）
- 其他表单控件（textarea、select、button）
- 表单验证（required、type、pattern、min/max）
- 最佳实践（label、placeholder）

**学习时间**：1.5 小时

**练习题**：创建一个联系表单

**答案文件**：`practice-solution.html`

---

### 5. 表格（05-tables）

**学习目标**：规范展示结构化数据

**内容要点**：

- 表格的基本结构（table、thead、tbody、tfoot）
- 表格标签（tr、th、td）
- 单元格合并（colspan、rowspan）
- 什么时候使用表格
- 最佳实践（使用 CSS 控制样式）

**学习时间**：1 小时

**练习题**：创建一个学生信息表

**答案文件**：`practice-solution.html`

---

### 6. 媒体与其他标签（07-media-misc）

**学习目标**：让网页更丰富、更专业

**内容要点**：

- 媒体标签（audio、video、source、track）
- 图文与说明（figure、figcaption、picture）
- 折叠内容（details、summary）
- 时间与联系（time、address）
- 模板与无脚本（template、noscript）

**学习时间**：1 小时

**练习题**：创建一个音乐欣赏页面

**答案文件**：`practice-solution.html`

---

### 7. 综合练习（06-html-practice）

**学习目标**：将学到的 HTML 知点整合运用

**内容要点**：

- 页面结构规划
- 内容组织思路
- 实现步骤（从规划到编码）
- 项目规范（文件命名、目录结构、代码组织）
- 完整示例：个人主页

**学习时间**：2 小时

**练习题**：创建一个完整的个人主页

**答案文件**：`practice-solution.html`

## 如何使用本教程

### 学习步骤

1. **阅读 README**：每个章节的 README.md 文件包含详细的概念讲解和学习要点
2. **查看示例**：打开对应的 HTML 文件，查看完整的代码示例
3. **动手实践**：按照 README 中的练习题要求，自己编写代码
4. **对照答案**：完成后参考 `practice-solution.html` 答案文件
5. **进阶挑战**：尝试完成进阶和挑战练习

---

### 学习建议

- **循序渐进**：按照章节顺序学习，不要跳过基础章节
- **动手实践**：光看不练假把式，一定要亲自写代码
- **多看多想**：理解每个标签的作用和适用场景
- **善用工具**：使用 VS Code 等代码编辑器，配合浏览器开发者工具
- **查漏补缺**：学习目标检查表可以帮助你确认掌握程度

---

### 学习时间

**总学习时间**：约 8-10 小时

| 学习阶段   | 时间     | 说明               |
| ---------- | -------- | ------------------ |
| 基础结构   | 30 分钟  | 理解 HTML 文档结构 |
| 常用标签   | 1 小时   | 掌握基本内容元素   |
| 语义化     | 1 小时   | 理解标签的语义     |
| 表单与验证 | 1.5 小时 | 学习表单交互       |
| 表格       | 1 小时   | 学习数据展示       |
| 媒体标签   | 1 小时   | 学习多媒体内容     |
| 综合练习   | 2 小时   | 整合所有知识点     |
| 复习巩固   | 1-2 小时 | 回顾和练习         |

## 常见问题

### Q1：我应该按照什么顺序学习？

A：建议按照章节顺序学习，从 01 到 07。每章内容都是循序渐进的，跳过基础章节可能会影响后续学习。

### Q2：练习题有答案吗？

A：是的，每个章节的基础练习题都有参考答案（`practice-solution.html`），可以在完成练习后对照查看。

### Q3：学习完本教程能做什么？

A：完成本教程后，你将能够：

- 创建标准的 HTML5 网页
- 使用各种 HTML 标签组织内容
- 创建表单收集用户输入
- 使用表格展示数据
- 嵌入音频、视频等多媒体内容
- 构建一个完整的个人主页

### Q4：接下来应该学习什么？

A：学完 HTML 基础后，建议继续学习：

- CSS：学习网页样式和布局
- JavaScript：学习网页交互和动态效果

### Q5：遇到问题怎么办？

A：可以查阅以下资源：

- MDN Web Docs：https://developer.mozilla.org/
- W3Schools：https://www.w3school.com.cn/
- Stack Overflow：https://stackoverflow.com/
