👂 侦听器详解

1. 侦听器基础

当前值: {{ message }}

侦听日志：

等待输入...
watch: { // 基础侦听器语法 message(newValue, oldValue) { console.log(`值从 "${oldValue}" 变为 "${newValue}"`) this.logs.push(`${new Date().toLocaleTimeString()}: "${oldValue}" → "${newValue}"`) } }

2. immediate 选项（立即执行）

执行记录（包含初始化时的执行）：

{{ log }}
watch: { immediateMessage: { handler(newValue, oldValue) { console.log('执行:', newValue) }, immediate: true // 初始化时立即执行一次 } }

3. deep 选项（深度侦听）

浅层侦听（无 deep）

修改姓名或年龄，观察右侧日志

侦听日志对比：

浅层侦听（无 deep）:
{{ log }}
未触发（除非替换整个 user 对象）
深度侦听（有 deep）:
{{ log }}
watch: { // 浅层侦听 - 只监听对象引用变化 user(newVal, oldVal) { console.log('浅层侦听触发') }, // 深度侦听 - 监听对象内部属性变化 user: { handler(newVal, oldVal) { console.log('深度侦听触发') }, deep: true } }

4. 侦听对象的特定属性

name 变化日志：

{{ log }}
watch: { // 使用字符串路径侦听特定属性 'user.name'(newName, oldName) { console.log(`姓名从 "${oldName}" 变为 "${newName}"`) } }

watch: { // 侦听用户名变化并验证 'form.username'(newValue) { if (!newValue) { this.validation.username = { valid: false, message: '用户名不能为空' } } else if (newValue.length < 3 || newValue.length > 20) { this.validation.username = { valid: false, message: '用户名长度应为3-20字符' } } else if (!/^[a-zA-Z0-9]+$/.test(newValue)) { this.validation.username = { valid: false, message: '只能包含字母和数字' } } else { this.validation.username = { valid: true, message: '✓ 用户名有效' } } } }
