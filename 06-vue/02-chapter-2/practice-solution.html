用户信息展示卡片

创建一个用户信息展示卡片，使用文本插值、v-html 和属性绑定。

👤 {{ userInfo.name }}

年龄: {{ userInfo.age }} 岁

职业: {{ userInfo.job }}

核心代码解析：

// 1. 文本插值 - 显示用户名和年龄
<h3>{{ userInfo.name }}</h3>
<p>年龄: {{ userInfo.age }} 岁</p>

// 2. v-html - 渲染带有样式的个人简介
<div v-html="userInfo.bio"></div>

// 3. 属性绑定 - 动态设置背景色
<div :style="{ backgroundColor: userCardColor }">...</div>
进阶练习

动态表单配置器

使用动态参数、修饰符创建可配置的表单元素。

当前值: "{{ inputValue }}"
长度: {{ inputValue.length }} 字符（自动去除首尾空格）

简介内容: {{ lazyBio || '（暂无内容）' }}

年龄值: {{ userAge }}
数据类型: {{ typeof userAge }}

核心代码解析：

// 1. 动态参数 :type 切换输入框类型
<input :type="inputType" v-model.trim="inputValue">

// 2. .trim 修饰符自动去除首尾空格
v-model.trim="inputValue"

// 3. .lazy 修饰符延迟更新（失去焦点后）
v-model.lazy="lazyBio"

// 4. .number 修饰符自动转换为数字
v-model.number="userAge" // typeof userAge === 'number'
挑战练习

动态组件渲染器

使用动态属性绑定和动态事件绑定创建可配置元素。

🎛️ 元素配置器

📦 渲染结果

{{ elementConfig.tag === 'button' || elementConfig.tag === 'a' ? '点击我触发 ' + elementConfig.eventName + ' 事件' : '' }}

💡 提示: {{ elementConfig.eventName }} 事件触发次数: {{ eventCount }}

当前配置代码：

<{{ elementConfig.tag }}
  {{ elementConfig.attrName }}="{{ elementConfig.attrValue }}"
  @{{ elementConfig.eventName }}="handleDynamicEvent">
点击我触发 {{ elementConfig.eventName }} 事件
</{{ elementConfig.tag }}>
核心技术解析：

// 1. 动态组件 - :is 指定标签类型
<component :is="elementConfig.tag">...</component>

// 2. 动态属性绑定 - 方括号语法
:[elementConfig.attrName]="elementConfig.attrValue"

// 3. 动态事件绑定 - 方括号语法
:@[elementConfig.eventName]="handleDynamicEvent"

// 组合使用实现完全动态的组件！
