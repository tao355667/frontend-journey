📝 模板语法详解 TypeScript

1. 文本插值（Mustache 语法）

最基本的文本绑定：{{ message }}

表达式计算：100 + 200 = {{ 100 + 200 }}

三元表达式：{{ isVip ? 'VIP会员' : '普通用户' }}

字符串操作：反转"{{ text }}" = "{{ text.split('').reverse().join('') }}"

// TypeScript 类型定义 interface AppData { message: string isVip: boolean text: string }

2. 原始 HTML 渲染（v-html）

纯文本输出：{{ htmlContent }}

HTML渲染：

// TypeScript 中 v-html 内容应为 string 类型 htmlContent: string = '<strong>内容</strong>'

3. 属性绑定（v-bind）

这个段落有动态 id: {{ dynamicId }}

访问 Vue 官网

这个 div 绑定了多个属性
// TypeScript 接口定义容器属性 interface ContainerAttrs { id: string class: string 'data-custom': string } containerAttrs: ContainerAttrs = { id: 'container', class: 'wrapper-class', 'data-custom': 'custom-value' }

4. JavaScript 表达式

单价: ¥{{ price }}

数量: {{ quantity }}

总价: ¥{{ price * quantity }}

折扣后（9折）: ¥{{ (price * quantity * 0.9).toFixed(2) }}

库存状态: {{ quantity > 0 ? '有货' : '缺货' }}

// TypeScript 类型安全的数据 data(): { price: number quantity: number } { return { price: 99.99, quantity: 1 } } // 方法也有类型定义 methods: { incrementQuantity(): void { this.quantity++ }, decrementQuantity(): void { this.quantity = Math.max(0, this.quantity - 1) } }

5. 指令参数

这是一个提示信息！

// TypeScript 中的事件处理程序 methods: { sayHello(): void { alert(`你好! 当前消息: ${this.message}`) }, showTip(): void { this.showTooltip = true }, hideTip(): void { this.showTooltip = false } }

6. 动态参数

选择要绑定的属性：

当前绑定属性: {{ selectedAttr }}

动态属性绑定示例
// TypeScript 中使用联合类型限制可选值 type AttributeName = 'href' | 'title' | 'id' selectedAttr: AttributeName = 'href' dynamicValue: string = 'https://example.com'

7. 修饰符

当前值: "{{ username }}"（长度: {{ username.length }}）

年龄值: {{ age }}，类型: {{ typeof age }}

简介: {{ bio }}

// TypeScript 中的表单数据类型 interface FormData { username: string age: number | null bio: string } // v-model.number 确保 age 是 number 类型 // 避免了 JavaScript 中 input 值默认为 string 的问题

综合示例：动态用户卡片

{{ user.name }}

年龄: {{ user.age }} 岁

职业: {{ user.job }}

// TypeScript 完整接口定义 interface User { name: string age: number job: string bio: string } interface AppData { user: User cardColor: string }
