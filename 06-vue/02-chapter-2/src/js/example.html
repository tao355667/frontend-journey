📝 模板语法详解

1. 文本插值（Mustache 语法）

最基本的文本绑定：{{ message }}

表达式计算：100 + 200 = {{ 100 + 200 }}

三元表达式：{{ isVip ? 'VIP会员' : '普通用户' }}

字符串操作：反转"{{ text }}" = "{{ text.split('').reverse().join('') }}"

// 双大括号 {{ }} 中的内容会被解析为 JavaScript 表达式 // 可以写：变量、计算、三元运算、方法调用等

3. 属性绑定（v-bind）

这个段落有动态 id: {{ dynamicId }}

4. JavaScript 表达式

单价: ¥{{ price }}

数量: {{ quantity }}

总价: ¥{{ price * quantity }}

折扣后（9折）: ¥{{ (price * quantity * 0.9).toFixed(2) }}

库存状态: {{ quantity > 0 ? '有货' : '缺货' }}

// 模板中只能使用表达式，不能使用语句 // ✓ {{ price * quantity }} - 表达式 // ✗ {{ var x = 1 }} - 语句（错误） // ✗ {{ if (ok) return x }} - 语句（错误）

7. 修饰符

当前值: "{{ username }}"（长度: {{ username.length }}）

年龄值: {{ age }}，类型: {{ typeof age }}

简介: {{ bio }}

// 修饰符以 . 开头 // .prevent - 阻止默认事件 // .stop - 阻止事件冒泡 // .trim - 自动过滤首尾空格 // .number - 自动转换为数字 // .lazy - 失去焦点后更新（而非实时）
