🧮 计算属性详解

1. 计算属性基础

原始数据:

  • firstName: {{ firstName }}
  • lastName: {{ lastName }}

计算属性:

  • 全名: {{ fullName }}
  • 姓名长度: {{ nameLength }}
  • 姓名反转: {{ reversedName }}
// 计算属性定义 computed: { // 简单的字符串拼接 fullName() { return this.firstName + ' ' + this.lastName }, // 基于计算属性再计算 nameLength() { return this.fullName.length }, // 复杂操作 reversedName() { return this.fullName.split('').reverse().join('') } }

2. Computed vs Methods 对比

Computed（有缓存）

执行次数: {{ computedExecCount }}

结果: {{ computedRandom }}

再次访问: {{ computedRandom }}

注意控制台输出：只执行一次

Method（无缓存）

执行次数: {{ methodExecCount }}

结果: {{ getMethodRandom() }}

再次调用: {{ getMethodRandom() }}

注意控制台输出：每次调用都执行

// 计算属性 - 有缓存 computed: { computedRandom() { console.log('计算属性执行了') // 只执行一次 this.computedExecCount++ return Math.random() } }, // 方法 - 无缓存 methods: { getMethodRandom() { console.log('方法执行了') // 每次调用都执行 this.methodExecCount++ return Math.random() } }

3. 复杂示例：购物车计算

商品 单价 数量 小计 操作
{{ item.name }} ¥{{ item.price }} {{ item.quantity }} ¥{{ item.price * item.quantity }}

计算属性统计：

商品总数: {{ totalItems }} 件

商品种类: {{ cart.length }} 种

小计金额: ¥{{ subtotal }}

VIP折扣: 9折

应付总额: ¥{{ finalPrice }}

// 购物车计算属性 computed: { // 计算商品总数 totalItems() { return this.cart.reduce((sum, item) => sum + item.quantity, 0) }, // 计算小计金额 subtotal() { return this.cart.reduce((sum, item) => { return sum + item.price * item.quantity }, 0) }, // 计算最终价格（考虑VIP折扣） finalPrice() { return this.isVip ? (this.subtotal * 0.9).toFixed(2) : this.subtotal.toFixed(2) } }

4. 可写计算属性（Getter + Setter）

示例1：全名分割

当前全名: {{ writableFullName }}

示例2：价格转换

汇率: 1 USD = 7.2 RMB

// 可写计算属性 computed: { writableFullName: { get() { return this.splitFirstName + ' ' + this.splitLastName }, set(newValue) { // newValue 是赋给计算属性的值 // 比如输入 "李 四"，分割后分别设置 firstName 和 lastName const parts = newValue.split(' ') this.splitFirstName = parts[0] || '' this.splitLastName = parts[1] || '' } }, usdPrice: { get() { return (this.rmbPrice / 7.2).toFixed(2) }, set(value) { this.rmbPrice = (value * 7.2).toFixed(2) } } }

5. 综合示例：成绩统计系统

统计结果（计算属性）：

总分: {{ totalScore }}

平均分: {{ averageScore }} 分

最高分: {{ maxScore }} 分

最低分: {{ minScore }} 分

及格状态: {{ allPassed ? '全部及格' : '有不及格科目' }}

// 成绩统计计算属性 computed: { totalScore() { return this.scores.reduce((sum, score) => sum + score, 0) }, averageScore() { return (this.totalScore / this.scores.length).toFixed(1) }, maxScore() { return Math.max(...this.scores) }, minScore() { return Math.min(...this.scores) }, allPassed() { return this.scores.every(score => score >= 60) } }
