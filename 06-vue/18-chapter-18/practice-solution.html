练习 3：Mixin 与 Composable 对比总结

Mixins vs Composables 对比

特性 Mixins (选项式) Composables (组合式)
命名冲突 ✗ 可能发生 ✓ 不会
来源追踪 ✗ 困难 ✓ 清晰
TypeScript 支持 ✗ 较差 ✓ 完美
Vue 3 推荐 ✗ 兼容 ✓ 推荐
代码组织 ✗ 分散 ✓ 集中
IDE 支持 ✗ 有限 ✓ 完整
结论：在 Vue 3 项目中，推荐使用 Composables 替代 Mixins 来实现逻辑复用。
