2. methods 方法定义

{{ calcResult !== null ? calcResult : calcDisplay }}
// methods 定义组件方法 methods: { calculate() { const { num1, num2, operator } = this switch(operator) { case '+': this.calcResult = num1 + num2; break case '-': this.calcResult = num1 - num2; break case '*': this.calcResult = num1 * num2; break case '/': this.calcResult = num2 !== 0 ? num1 / num2 : '错误' } }, resetCalc() { this.num1 = 0 this.num2 = 0 this.operator = '+' this.calcResult = null } }

3. 方法间的互相调用

当前等级: {{ level }}

当前经验: {{ exp }}

升级所需: {{ expNeeded }}

// 方法间可以互相调用 methods: { gainExp(amount) { this.exp += amount this.checkLevelUp() // 调用另一个方法 }, checkLevelUp() { if (this.exp >= this.expNeeded) { this.levelUp() } }, levelUp() { this.level++ this.exp = 0 this.expNeeded = this.level * 100 alert(`恭喜升级到 ${this.level} 级！`) } }

4. 响应式数组操作

// 响应式数组方法 methods: { addNewProduct() { // push 方法会触发响应式更新 this.products.push({ id: Date.now(), name: this.newProductName, price: this.newProductPrice }) }, removeProduct(id) { // filter 返回新数组，也是响应式的 this.products = this.products.filter(p => p.id !== id) } }

5. 复杂对象操作

购物车

会员状态: {{ cart.isVip ? 'VIP会员' : '普通用户' }}

商品数量: {{ cart.items.length }}

总价: ¥{{ cart.total }}

{{ item.name }} ¥{{ item.price }} × {{ item.quantity }}
// 操作嵌套对象 data() { return { cart: { items: [], total: 0, isVip: false } } }, methods: { addToCart(product) { // 修改嵌套对象的属性是响应式的 this.cart.items.push({...product, quantity: 1}) this.updateCartTotal() }, updateCartTotal() { // 计算总价 this.cart.total = this.cart.items.reduce((sum, item) => { return sum + item.price * item.quantity }, 0) // VIP 享受9折优惠 if (this.cart.isVip) { this.cart.total *= 0.9 } } }

6. ⚠️ 常见注意事项

不要直接修改数组长度：

列表长度: {{ demoList.length }}

  • {{ item }}
// ✗ 错误 - 直接修改 length 不会触发更新 wrongClear() { this.demoList.length = 0 // 视图不会更新！ } // ✓ 正确 - 使用 splice 或赋新数组 correctClear() { this.demoList.splice(0, this.demoList.length) // 或者 this.demoList = [] }
