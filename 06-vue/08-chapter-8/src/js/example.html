📋 列表渲染演示

1. 基础 v-for 数组渲染

  • {{ index + 1 }}. {{ todo.text }}

暂无事项

{{ todos.length }}
总计
{{ activeCount }}
进行中
{{ completedCount }}
已完成
<li v-for="(todo, index) in todos" :key="todo.id"> {{ index + 1 }}. {{ todo.text }} </li>

2. 商品列表示例

{{ product.icon }}
{{ product.name }}
¥{{ product.price }}
{{ product.stock === 0 ? '缺货' : `库存: ${product.stock}` }}

💡 key 属性的重要性

key 帮助 Vue 识别哪些元素改变了，从而高效地更新 DOM。推荐使用唯一 ID 作为 key。

3. 使用 v-for 遍历对象

{{ index + 1 }}. {{ key }}: {{ value }}
<div v-for="(value, key, index) in object" :key="key"> {{ index }}. {{ key }}: {{ value }} </div>

4. 范围渲染（v-for with Number）

{{ n }}
<span v-for="n in 10" :key="n">{{ n }}</span>

💡 提示

v-for 也可以直接使用数字作为范围，常用于分页按钮、评分星星等场景。
