💡 v-show vs v-if

v-show 只是切换 CSS 的 display 属性，元素始终存在于 DOM 中，适合频繁切换的场景。

🎯 使用建议

• v-if：条件很少改变，或初始条件为 false 时
• v-show：需要频繁切换显示/隐藏时

5. 在 <template> 上使用条件

<template v-if="condition"> <div>元素 1</div> <div>元素 2</div> <div>元素 3</div> </template>

💡 <template> 的作用

<template> 不会渲染为实际的 DOM 元素，可以用来包裹多个元素进行条件渲染，避免额外的包装 div。
