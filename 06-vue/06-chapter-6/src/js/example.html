1. Class 绑定 - 对象语法

基础对象语法
当前应用的 class: {{ getActiveClasses }}
绑定对象变量
直接绑定 classObject 对象
// Class 对象语法 // 模板中 <div :class="{ active: isActive, 'text-danger': hasError }"> // 或绑定整个对象 <div :class="classObject"> // data 中 data() { return { classStates: { active: true, error: false, highlight: false, largeText: false }, classObject: { active: true, highlight: true } } }

2. Class 绑定 - 数组语法

选择要应用的 class：

数组语法
直接应用三个 class 变量
数组 + 三元表达式
根据条件动态选择
数组 + 对象语法混合
静态 class + 动态对象
// Class 数组语法 // 基础用法 <div :class="[activeClass, errorClass]"> // 三元表达式 <div :class="[isActive ? activeClass : '', errorClass]"> // 数组中使用对象 <div :class="[classA, { active: isActive }]"> data() { return { activeClass: 'active', errorClass: 'error', highlightClass: 'highlight' } }

3. Style 绑定 - 对象语法

调整样式：

动态样式卡片
实时调整样式属性
绑定 styleObject
直接绑定整个样式对象
// Style 对象语法 // 内联对象 <div :style="{ color: activeColor, fontSize: fontSize + 'px' }"> // 驼峰命名或短横线命名（需引号） <div :style="{ backgroundColor: bgColor, 'border-radius': '8px' }"> // 绑定对象变量 <div :style="styleObject"> data() { return { styles: { color: '#42b883', backgroundColor: '#f0f0f0', fontSize: 16, padding: 20, borderRadius: 8 }, styleObject: { color: '#764ba2', fontSize: '18px', padding: '15px', backgroundColor: '#f3e5f5' } } }

4. Style 绑定 - 数组语法

样式合并示例：

baseStyles + overrideStyles，后面的属性会覆盖前面的

数组合并样式
baseStyles 定义基础样式，overrideStyles 覆盖特定属性

baseStyles 颜色: {{ baseStyles.color }}
overrideStyles 颜色: {{ overrideStyles.color }}
最终颜色: {{ overrideStyles.color }}（被覆盖）
// Style 数组语法 // 多个对象合并，后面的属性覆盖前面的 <div :style="[baseStyles, overrideStyles]"> data() { return { baseStyles: { fontSize: '16px', color: '#333', backgroundColor: '#f5f5f5' }, overrideStyles: { color: '#42b883', // 覆盖 baseStyles 中的 color fontWeight: 'bold' // 新增属性 } } }
