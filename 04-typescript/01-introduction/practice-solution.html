练习 1.1：个人信息输出

题目：创建一个 TypeScript 程序，定义你的个人信息，包括姓名（string）、年龄（number）、是否是学生（boolean），并在控制台输出这些信息。

TypeScript 代码：

// 定义个人信息
const myName: string = "张三";
const myAge: number = 25;
const isStudent: boolean = false;

// 输出信息
console.log(`姓名: ${myName}`);
console.log(`年龄: ${myAge}`);
console.log(`是否是学生: ${isStudent}`);

// 使用模板字符串格式化输出
console.log(`\n个人信息摘要：`);
console.log(`我叫${myName}，今年${myAge}岁，${isStudent ? '是学生' : '不是学生'}。`);

运行结果：

姓名: 张三
年龄: 25
是否是学生: false

个人信息摘要：
我叫张三，今年25岁，不是学生。

练习 1.2：乘法函数

题目：编写一个函数，接收两个数字参数，返回它们的乘积。在主程序中调用这个函数并输出结果。

TypeScript 代码：

// 乘法函数，参数和返回值都有类型注解
function multiply(a: number, b: number): number {
  return a * b;
}

// 调用函数
const num1: number = 7;
const num2: number = 8;
const result: number = multiply(num1, num2);

console.log(`${num1} × ${num2} = ${result}`);

// 多组测试
console.log(`\n乘法表测试：`);
console.log(`3 × 4 = ${multiply(3, 4)}`);
console.log(`5 × 6 = ${multiply(5, 6)}`);
console.log(`9 × 9 = ${multiply(9, 9)}`);

运行结果：

7 × 8 = 56

乘法表测试：
3 × 4 = 12
5 × 6 = 30
9 × 9 = 81

练习 1.3：矩形面积计算

题目：创建一个表示矩形的接口 Rectangle，包含 width（宽度）和 height（高度）两个属性。编写一个函数计算矩形的面积，返回 number 类型。

TypeScript 代码：

// 定义矩形接口
interface Rectangle {
  width: number;
  height: number;
}

// 计算矩形面积的函数
function calculateArea(rect: Rectangle): number {
  return rect.width * rect.height;
}

// 测试
const myRectangle: Rectangle = {
  width: 10,
  height: 5
};

const area: number = calculateArea(myRectangle);
console.log(`矩形尺寸: ${myRectangle.width} × ${myRectangle.height}`);
console.log(`矩形面积: ${area}`);

// 多个矩形测试
const rectangles: Rectangle[] = [
  { width: 4, height: 3 },
  { width: 7, height: 2 },
  { width: 6, height: 6 }
];

console.log(`\n多个矩形面积计算：`);
rectangles.forEach((rect, index) => {
  const rectArea = calculateArea(rect);
  console.log(`矩形${index + 1} (${rect.width}×${rect.height}): ${rectArea}`);
});

运行结果：

矩形尺寸: 10 × 5
矩形面积: 50

多个矩形面积计算：
矩形1 (4×3): 12
矩形2 (7×2): 14
矩形3 (6×6): 36

练习 1.4：三维坐标点距离计算

题目：创建一个表示三维坐标的点接口 Point3D，包含 x、y、z 三个属性。编写一个函数计算两个三维坐标点之间的距离。提示：距离公式为 √((x2-x1)² + (y2-y1)² + (z2-z1)²)。

TypeScript 代码：

// 定义三维坐标点接口
interface Point3D {
  x: number;
  y: number;
  z: number;
}

// 计算两点之间的距离
function calculateDistance(point1: Point3D, point2: Point3D): number {
  const dx = point2.x - point1.x;
  const dy = point2.y - point1.y;
  const dz = point2.z - point1.z;

  // 使用勾股定理计算距离
  return Math.sqrt(dx * dx + dy * dy + dz * dz);
}

// 测试
const pointA: Point3D = { x: 0, y: 0, z: 0 };
const pointB: Point3D = { x: 3, y: 4, z: 12 };

const distance = calculateDistance(pointA, pointB);
console.log(`点A: (${pointA.x}, ${pointA.y}, ${pointA.z})`);
console.log(`点B: (${pointB.x}, ${pointB.y}, ${pointB.z})`);
console.log(`两点间距离: ${distance}`);

// 验证：3-4-12 三角形的斜边应该是 13
console.log(`\n验证：3-4-12 直角三角形的斜边应为 13，实际计算结果: ${distance}`);

// 更多测试
const pointC: Point3D = { x: 1, y: 2, z: 2 };
const pointD: Point3D = { x: 4, y: 6, z: 5 };
const distance2 = calculateDistance(pointC, pointD);
console.log(`\n点C到点D的距离: ${distance2.toFixed(2)}`);

运行结果：

点A: (0, 0, 0)
点B: (3, 4, 12)
两点间距离: 13

验证：3-4-12 直角三角形的斜边应为 13，实际计算结果: 13

点C到点D的距离: 5.00
