BEM 命名规范演示

什么是 BEM？

BEM (Block, Element, Modifier) 是一种 CSS 命名方法论，旨在创建可维护和可扩展的 CSS 代码。它通过清晰的命名约定来组织样式，提高代码的可读性和可维护性。

BEM 命名规则

  • Block (块)：独立的实体，可重用
    例：.card, .button, .nav
  • Element (元素)：块的组成部分，不能独立使用
    例：.card__title, .button__icon, .nav__link
  • Modifier (修饰符)：块或元素的变化状态或版本
    例：.card--featured, .button--primary, .nav--vertical

BEM 语法示例

/* 块 (Block) */ .card { } /* 元素 (Element) */ .card__header { } .card__title { } .card__body { } /* 修饰符 (Modifier) */ .card--featured { } .card--dark { } /* 块 + 元素 + 修饰符 */ .card__title--large { } .button--primary { } .nav--vertical { }

BEM 优势

🎯 清晰的结构

通过命名约定清楚表达组件结构和关系，提高代码可读性。

🔄 可维护性

模块化的命名方式使得代码易于维护和修改，降低维护成本。

📦 可重用性

组件化的设计使得样式可以在不同项目中重用，提高开发效率。

🚫 避免冲突

独特的命名方式减少了 CSS 选择器的冲突，提高代码稳定性。

最佳实践

  • 保持简单：不要过度嵌套，通常 2-3 层就足够了
  • 语义化命名：使用有意义的名称，避免缩写和简写
  • 一致性：在整个项目中保持命名规范的一致性
  • 避免 ID：尽量使用类而不是 ID，提高可重用性
  • 修饰符使用：当需要改变块或元素的外观或状态时使用修饰符

常见误区

  • 过度嵌套：如 .block__elem1__elem2（应该创建新的块）
  • 元素独立使用：如单独使用 .card__title（应该配合 .card）
  • 修饰符代替块：如 .button--primary（应该配合 .button）
  • 命名过长：保持命名简洁明了
