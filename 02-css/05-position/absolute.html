绝对定位 (position: absolute) 演示

什么是绝对定位？

绝对定位是相对于最近的已定位祖先元素进行定位。如果没有已定位的祖先元素，则相对于初始包含块（通常是 body）进行定位。绝对定位的元素脱离正常文档流。

绝对定位的特点

  • 脱离文档流：元素不占据原始空间
  • 相对定位：相对于最近的已定位祖先元素
  • 精确定位：可以使用 top、right、bottom、left 精确控制位置
  • 支持 z-index：可以控制元素的层级
  • 常用场景：下拉菜单、模态框、工具提示、装饰元素等

定位参考点

  • 有定位祖先：相对于最近的 position 不为 static 的祖先
  • 无定位祖先：相对于初始包含块（通常是 body）
  • fixed 定位：相对于视口（浏览器窗口）

使用建议

  • 确保父元素有 position 属性（通常是 relative）
  • 合理使用 z-index 避免层级混乱
  • 考虑响应式设计，在小屏幕上调整定位
  • 结合 JavaScript 可以创建更复杂的交互效果
