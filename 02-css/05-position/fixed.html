CSS 固定定位演示

什么是固定定位？

固定定位是相对于浏览器视口进行定位。元素会固定在屏幕的特定位置，即使页面滚动也不会移动。固定定位的元素脱离正常文档流。

固定定位的特点

  • 相对于视口定位：始终相对于浏览器窗口
  • 固定位置：页面滚动时位置不变
  • 脱离文档流：不占据原始空间
  • 支持 z-index：可以控制层级
  • 常用场景：导航栏、侧边栏、浮动按钮等

常见应用场景

🧭 固定导航栏

页面顶部的导航栏始终保持可见，方便用户随时访问主要功能。

📋 固定侧边栏

侧边导航或目录，在滚动页面时保持可见，提供快速导航。

⬆️ 返回顶部按钮

方便用户快速返回页面顶部，改善用户体验。

💬 聊天按钮

固定的客服聊天入口，随时为用户提供帮助。

📢 固定通知

重要的通知信息固定显示，确保用户看到。

📊 固定进度条

显示阅读进度或其他进度信息。

技术特性

position: fixed;
top: 0;
left: 0;
right: 0;
z-index: 1000;

固定定位使用与绝对定位相同的属性，但参考点不同：

  • top, bottom, left, right：相对于视口的距离
  • z-index：控制元素的层级
  • width, height：可以设置固定尺寸

使用建议

  • 合理使用 z-index：避免层级混乱
  • 考虑响应式设计：在小屏幕上可能需要隐藏或调整
  • 注意遮挡问题：避免遮挡重要内容
  • 性能考虑：过多固定元素可能影响滚动性能
  • 用户体验：确保固定元素不会干扰正常浏览
