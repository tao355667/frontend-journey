CSS盒模型演示

什么是盒模型？

CSS盒模型是网页布局的基础。每个HTML元素都可以看作一个矩形的盒子，由内容(content)、内边距(padding)、边框(border)和外边距(margin)组成。

基础盒模型

这是一个基础盒模型演示

box-sizing 属性对比

content-box (默认)

width: 200px

padding: 20px

border: 5px

总宽度: 250px

border-box

width: 200px

padding: 20px

border: 5px

总宽度: 200px

box-sizing: border-box 的优势

使用 border-box 可以让元素的宽度和高度包含内边距和边框，这样在设置元素大小时更加直观和可预测。

最佳实践

  • 使用 box-sizing: border-box 简化布局计算
  • 合理使用外边距创建元素间距
  • 使用内边距为内容创建呼吸空间
  • 边框不仅可以装饰，还可以用于视觉分组
  • 圆角可以让设计更加现代和友好
