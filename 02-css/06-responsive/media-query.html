什么是媒体查询？

媒体查询是 CSS3 的一个重要特性，它允许根据设备的特性（如屏幕宽度、高度、方向等）应用不同的样式。这是实现响应式设计的核心技术。

响应式网格布局

这个网格会根据屏幕宽度自动调整列数：

  • 移动设备 (<768px)：单列
  • 平板设备 (≥768px)：2列
  • 桌面设备 (≥1024px)：3列
  • 大屏设备 (≥1200px)：4列

响应式标题

这段文字的大小会根据屏幕尺寸自动调整。在移动设备上使用较小的字体，在桌面设备上使用较大的字体，以提供最佳的阅读体验。

响应式设计不仅仅是布局的调整，还包括文字大小、间距、颜色等各个方面的优化，确保用户在任何设备上都能获得良好的体验。

媒体查询语法

/* 基本语法 */ @media (min-width: 768px) { /* 平板设备样式 */ } /* 多个条件 */ @media (min-width: 768px) and (max-width: 1024px) { /* 平板设备专用样式 */ } /* 设备特性 */ @media (orientation: landscape) { /* 横屏样式 */ } /* 高分辨率屏幕 */ @media (-webkit-min-device-pixel-ratio: 2) { /* Retina 屏幕样式 */ } /* 打印样式 */ @media print { /* 打印专用样式 */ }

常用断点

/* 移动设备 */ @media (max-width: 767px) { } /* 平板设备 */ @media (min-width: 768px) and (max-width: 1023px) { } /* 桌面设备 */ @media (min-width: 1024px) { } /* 大屏设备 */ @media (min-width: 1200px) { }

响应式设计原则

  • 移动优先：先为移动设备设计，再增强到桌面设备
  • 流式布局：使用相对单位而非固定像素
  • 弹性图片：图片能够自适应容器大小
  • 媒体查询：根据设备特性应用不同样式
  • 性能优化：针对不同设备优化加载和性能

测试方法

  • 使用浏览器开发者工具的设备模拟器
  • 调整浏览器窗口大小测试响应式效果
  • 在真实设备上测试体验
  • 测试不同屏幕方向的显示效果
