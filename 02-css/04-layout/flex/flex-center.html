Flexbox 居中的优势

Flexbox 提供了简单而强大的居中对齐方法，解决了传统 CSS 中复杂的居中问题。无论是水平居中、垂直居中，还是完美居中，都可以轻松实现。

justify-content: center;
align-items: center;

Flexbox 居中技巧总结

  • 完美居中：justify-content: center + align-items: center
  • 水平居中：justify-content: center
  • 垂直居中：align-items: center
  • margin auto：在 flex 容器中使用 margin: auto
  • 响应式：结合 min-height 和 padding 实现响应式居中
  • 固定定位：position: fixed + flex 实现全屏居中
