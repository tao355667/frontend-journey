Flexbox 基础演示

什么是 Flexbox？

Flexbox（弹性盒子）是一种一维布局方法，用于在容器中分配空间和对齐项目。它特别适合用于组件级别的布局。

Flexbox 优势

  • 简单的语法，易于理解和使用
  • 强大的对齐能力
  • 响应式设计的理想选择
  • 解决垂直居中等经典布局问题
  • 浏览器支持良好
